## About finance-forge.ai

finance-forge.ai is a free, ad-free reference for Canadian personal finance —
tax rates, contribution limits, registered-account guides, and a working income
tax calculator for every province and territory except Quebec.

The site is run by a Canadian CPA. The goal is plain: publish accurate,
current-year figures and explain how they fit together, without the marketing
clutter and pop-ups that bury the actual numbers on most financial sites. There
are no ads, no subscription gates, no affiliate links, and no email wall. Every
page carries a "Revised" date so you always know how current it is, and every
bracket and contribution figure is sourced from a versioned data file so it
moves forward consistently each October when CRA publishes new indexation.

If you find a figure that looks wrong, or a topic that's missing, please send a
note — corrections from readers are how the site gets sharper.
